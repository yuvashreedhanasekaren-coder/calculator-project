# 🧮 Calculator Project

A modern and responsive calculator built using **HTML**, **CSS**, and **JavaScript**. This project performs basic arithmetic operations with a clean and user-friendly interface.

## 🚀 Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 🔢 Decimal calculations
- 🗑️ Clear (AC)
- ⌫ Delete (DEL)
- 📱 Responsive Design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (DOM)

## 📂 Project Structure

```
calculator-project/
│── index.html
│── style.css
│── script.js
│── README.md
```

## ▶️ How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Double-click `index.html` or open it in your browser.
