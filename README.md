# 🧮 Calculator Project

A modern and responsive calculator built using **HTML**, **CSS**, and **JavaScript**. This project performs basic arithmetic operations with a clean and user-friendly interface.

## 🚀 Features

- Basic arithmetic operations (+, −, ×, ÷)
- Responsive design
- Modern user interface
- Easy-to-use button layout
- Clean and organized code structure

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 📂 Project Structure

```
calculator-project/
│── index.html
│── style.css
│── script.js
│── README.md
```

## ▶️ How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
